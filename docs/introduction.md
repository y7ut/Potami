# Potami: 新一代 AI 应用开发与编排框架

欢迎来到 Potami (波塔米) 的世界！

Potami 是一个为构建、部署和管理由大型语言模型（LLM）驱动的复杂应用而设计的现代化框架。它通过一套强大的工作流（Stream）和任务节点（Job）系统，将繁琐的 Prompt Engineering、多服务协同、数据处理等过程，转化为清晰、可维护且高效的声明式配置。

## 核心设计哲学

在 Potami 中，我们相信**声明式优于命令式**。您只需要通过简单的 YAML 文件描述您**想要什么**，而无需关心**如何实现**。Potami 的内核会负责处理任务的并发、调度、数据流转、错误重试和状态监控等所有底层细节。

## 关键特性

- **声明式工作流 (Stream)**: 使用直观的 YAML 文件定义由多个任务节点（Job）组成的复杂AI应用逻辑。
- **管道化数据流**: 数据在工作流的各个节点间自动流转和传递，后续节点可以无缝使用上游节点的输出。
- **动态与热更新**: 在服务不重启的情况下，可以随时更新或创建新的工作流，实现业务的快速迭代。
- **高并发与优先级控制**: 基于高性能的协程池，有效控制系统并发量，并可为重要任务设置更高优先级，确保关键业务的稳定性。
- **全面的可观测性**:
    - **实时状态推送**: 通过 SSE (Server-Sent Events) 实时获取任务执行的每一个步骤的状态。
    - **进度查询**: 将任务的详细进度持久化，可随时通过 API 查询。
    - **异步回调**: 支持任务完成后自动调用指定的回调地址，轻松集成到现有业务流程中。
- **强大的命令行工具 (`potactl`)**: 提供从工作流创建、调试、管理到状态监控的全套命令行工具，极大提升开发效率。

## Potami 适合做什么？

- **构建高级 RAG (检索增强生成) 应用**: 轻松编排 `loader` -> `corpus_search` -> `prompt` 的流程，构建企业级知识库问答系统。
- **自动化内容创作**: 将内容抓取、多步分析、大纲生成、正文写作、摘要提炼等步骤串联成一个自动化的内容生产线。
- **多 API 服务编排**: 将多个外部 API 和内部服务与 LLM 的能力相结合，创造出强大的新功能。
- **复杂 Flow 实现**: 通过定义一系列工具（Tool Job）和决策（Prompt Job），构建能够自主完成复杂任务的智能代理。
